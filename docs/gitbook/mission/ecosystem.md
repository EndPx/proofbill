# Contribution to the NEAR Ecosystem

ProofBill explores how NEAR accounts, NFTs, and private AI services can work together in a purchasing application. The owner authorizes a budget, an agent requests a service, and settlement remains tied to a specific delivery and seller.

| Component | Responsibility |
| --- | --- |
| NEAR accounts and contracts | Separate owner, agent, publisher, and seller identities |
| NEP-171 NFT ownership | Represent the funded entitlement and its holder |
| Native testnet NEAR | Fund service allocation, storage, and wallet gas |
| NEAR AI Cloud | Produce extraction responses and provider evidence |
| Wallet-message signing | Authenticate private access without making a payment |

The public repository includes the contract, agent SDK, worker, independent buyer verifier, and public receipt projection. Developers can inspect boundaries and repeat local checks rather than relying only on a video.

The implemented capabilities relate to agent purchasing, private AI delivery, user-controlled spending, and NFT utility. This maps technical capabilities; it does not claim automatic eligibility for every hackathon track, sponsor endorsement, or independently measured adoption.
