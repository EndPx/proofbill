# Overview

Use ProofBill as a budget owner, an external-agent developer, or a reviewer reading public payment facts. Public receipts do not require a wallet; private work requires account authentication.

| Goal | Guide |
| --- | --- |
| Connect on the correct network | [Getting Started](getting-started.md) |
| Fund, run, review, and refund | [For Budget Owners](budget-owners.md) |
| Connect an agent you control | [Bring Your Own Agent](own-agent.md) |
| Understand price, permission, and privacy | [Frequently Asked Questions](faq.md) |

Open the [live workspace](https://proofbill-two.vercel.app/app/purchases). Use testnet funds and synthetic briefs while evaluating the MVP. Connecting, signing a login message, assigning an agent, and approving payment are different actions.
