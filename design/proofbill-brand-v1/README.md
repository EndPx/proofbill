# ProofBill logo concept v1

Created with ChatGPT's built-in image generation tool on 13 November 2026. Raster PNG brand artwork, not SVG/vector source. This is the first logo proposal for the planned product, not an assertion of final user approval.

## Concept

A mint receipt with a verification check pairs the two parts of the name: a record of the purchase and inspectable evidence. The folded corner and shallow receipt notches connect it to Purchase Pass/order receipts. Geometric bold ProofBill wordmark complements the black app frame and white rounded content surface.

## Selected files

- `proofbill-logo-on-light.png`: horizontal dark wordmark, transparent background, for light surfaces.
- `proofbill-logo-on-dark.png`: horizontal white wordmark on an opaque charcoal panel, for dark brand presentations. This file is NOT transparent.
- `proofbill-icon.png`: square standalone receipt/check source with transparent background, for project avatar and future favicon export.
- `PROMPTS.md`: complete selected generation prompts and the reference relationships.

The opaque dark version was selected over the transparent white-wordmark attempts because their edge artifacts were visibly worse. Those attempts remain only in the generator output location, not this selected package. Generated color/edge texture is raster artwork and should not be described as exact vector geometry.

## Usage

Use mint and the near-black check consistently. Preserve aspect ratio and allow clear space around the mark. Do not stretch, add glow, or place the dark wordmark on the charcoal app shell. Future implementation can pair the icon with a real text wordmark for crisp small UI text; no frontend implementation was changed in this task.

The first three files are the deliverables. Runtime app assets and rendered UI concepts have not been replaced automatically.
