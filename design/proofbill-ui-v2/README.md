# ProofBill UI concept v2

Static mockups, revised to the user's NEAR activity screenshot reference. No application code was implemented. All data, names, dates and balances shown are illustrative.

## Approved direction requested by the user

- Continuous charcoal `#252525` outer shell and dark sidebar.
- A single white `#FFFFFF` main sheet inset from top, right and bottom, with rounded corners around 22–26px and a visible narrow dark rim.
- Black primary buttons with white text, neutral secondary surfaces and hairline gray dividers.
- Small mint accents for branding/success and amber for review states.
- ProofBill's own order, budget, evidence and receipt content; the NEAR screenshot supplies visual structure only.

## Files

- `01-purchases-dashboard.png`: budget sidebar, order table, review receipt and active permit.
- `02-order-detail.png`: result, scoped evidence, exact payment approval and timeline.
- `PROMPTS.md`: full prompts used with the built-in image generation tool.

## Constraints

This is a concept, not a working product screenshot or final identity system. Testnet amounts are explicit. A matched model signature does not establish answer correctness. TLS binding remains not checked. Order #104 is not paid. Mockup timestamps are illustrative.

Source reference: user-provided screenshot of https://near.com/activity?type=limit. The public web reader could not load that route; the attached screenshot was inspected directly.
